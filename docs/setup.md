# 導入手順

所要時間の目安は30分です。上から順に進めます。

## 1. ソリューションをインポートする

1. [Power Automate](https://make.powerautomate.com/) を開き、左のメニューから「ソリューション」を選ぶ
2. 上の「ソリューションをインポート」→「参照」で `KozaOpsKit.zip` を選び、「次へ」
3. 接続の選択画面で、次の3つにそれぞれ自分の接続を選ぶ（無ければ「新しい接続」で作る）
   - SharePoint
   - Office 365 Outlook
   - Microsoft Forms
4. 環境変数の入力画面で、次の3つを入れる

| 環境変数 | 入れる値 | 例 |
|---|---|---|
| 講座キット：SharePoint サイトのURL | リストを置くサイトのURL | `https://contoso.sharepoint.com/sites/koza` |
| 講座キット：申込みフォームのID | 手順3で作る申込みフォームのID | まだ無ければ仮の値のままでよい |
| 講座キット：アンケートフォームのID | 手順3で作るアンケートのID | まだ無ければ仮の値のままでよい |

5. 「インポート」を押す。数分で「講座運営 自動化キット」がソリューションの一覧に出る

フローは10本ともオフで入ります。

## 2. リストを作る（00 を1回実行する）

1. ソリューション「講座運営 自動化キット」を開き、「00 リストを作る（最初に1回だけ実行）」を開く
2. 「オンにする」→「実行」→「フローの実行」
3. 1〜2分待ち、SharePoint サイトに次の5つのリストができていることを確かめる

| リスト | 1行の意味 |
|---|---|
| 講座スケジュール | 講座の1回 |
| 出席管理 | 1人の1回分の申込み |
| アンケート回答 | 1回答 |
| バッジ一覧 | 1つのバッジ |
| バッジ授与記録 | 1人に1回渡した記録 |

列の中身は [design.md](design.md) にあります。00 は列を英語の内部名で作ってから、表示名を日本語にしています。フローは内部名で列を読み書きするので、列名を変えるときは表示名だけを変えます。

リストができたら、00 はオフに戻して構いません。

## 3. Forms を2つ作る

[forms/questions.md](../forms/questions.md) のとおりに、申込みフォームとアンケートを作ります。

- どちらも「この組織内のユーザーのみが回答可能」にして、「名前を記録」をオンにする（フローは回答者のメールアドレスを使うため）
- 「講座回」の質問の選択肢は、講座スケジュールのタイトル（講座回）と同じ文字にする

### フォームIDの調べ方

1. Forms でフォームを開く
2. ブラウザーのアドレス欄の `id=` の後ろ（次の `&` まで）がフォームID

### 環境変数にフォームIDを入れる

1. ソリューション「講座運営 自動化キット」→ 左の「環境変数」
2. 「講座キット：申込みフォームのID」を開き、「現在の値」に申込みフォームのIDを入れて保存
3. 「講座キット：アンケートフォームのID」も同じように入れる

## 4. Forms の質問をフローに結び付ける（2本だけ）

Forms の質問IDはフォームごとに違うため、次の2本だけ画面で選び直します。

**01 申込みの受付**
1. フローを開いて「編集」
2. 「作成」アクションを開き、入力欄の文字を消して、動的コンテンツから「講座回」の質問を選ぶ
3. 保存

**06 回答の記録**
1. フローを開いて「編集」
2. 「作成」「作成 1」「作成 2」の3つを開き、それぞれ動的コンテンツから「講座回」「理解度」「感想」の質問を選ぶ
3. 保存

## 5. オンにする

01〜09 を順に開き、「オンにする」を押します。

## 6. 使い方

1. 講座スケジュールに講座の回を1行追加する（講座回・開催日時・開催実績＝開催予定）
2. Teams 会議を作ったら、会議URLを入れる → 03 が翌朝8時に参加URLを送る
3. 開催前日の9時に 04 がリマインドを送る
4. 開催後、開催実績を「開催済み」にし、アンケートURL・資料URLを入れて、配信承認を「はい」にする → 05・07 が送る
5. バッジ一覧に、その回のバッジ（講座回・画像URL）を1行入れておく → アンケートに回答した人に 08 がバッジを送る
6. 延期・中止のときは、開催実績を変えて配信承認を「はい」にする → 09 が送る

## うまく動かないとき

| 症状 | 確かめるところ |
|---|---|
| 01・06 が動かない | 環境変数のフォームIDが正しいか。フローをオンにした後に回答したか |
| 出席管理に行が増えない | 01 の「作成」で講座回の質問を選んだか |
| メールが届かない | 講座回の文字が、講座スケジュールと出席管理で完全に同じか |
| バッジの画像が表示されない | 画像URLが、受け取る人が開ける場所にあるか |
| 同じメールが届かない（2回目） | 正常です。送信済みの列が「はい」の回には送りません |
